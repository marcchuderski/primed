# Primed

Persönliche Web-App (PWA) für trainingsadaptives Ernährungs- und Protein-Tracking.
Tagesarten mit eigenen Sollwerten, Meal-Prep-Vorrat, Barcode-Scan, regelbasierte Vorschläge und ein Verlauf über Woche, Monat und Jahr.
